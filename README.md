# Roadmap Generator

This is a SNOMED Implemenation Roadmap Generator, inteded for educational use. Currently in Alpha stages.

## Demo app

The app is available for demonstration in [this site](https://ihtsdo.github.io/roadmap-generator/).

## Claude skill

A [Claude Code skill](.claude/skills/roadmap-creation/SKILL.md) is included that creates roadmaps following the same structure, content library and branding as this app — including importing step data from JIRA, Google Sheets, CSV and other sources. The skill is self-contained (it can be copied and used outside this repository) and produces `roadmap.json` files that can be uploaded into the demo app.
